中国节假日日历

保留 Windows 原生日历，在日期格里查看放假、补班安排。

安装后怎么用

点击任务栏右下角的时间，展开 Windows 日历。休 表示放假，班 表示调休上班。未标记的日期保持原样，不代表一定上班。

安装包已经包含运行依赖，无需安装 Python、Windhawk，也无需输入命令。登录后会自动启用；若刚安装尚未显示，可在开始菜单打开“中国节假日日历”并点击“启用标记”。

更换主题和背景

在开始菜单打开“中国节假日日历”，选择日历主题和背景类型，再点击“应用主题”。共提供二十套主题，其中新增十套二次元、国风、科技与幻想主题，每套都可使用插画、渐变或纯色背景。选择“系统默认”可以恢复原外观；休／班标记仍保留。

主题设计图不是系统实拍，原生日历的实际布局取决于 Windows 版本、缩放和当前显示内容。应用后请重新展开系统日历查看；若未更新，可暂停再启用。

明年还要导入吗

不用。程序每七天自动检查上一年、当年、下一年的数据，不随登录重复联网。也可以在管理窗口点击“立即更新”。明年正式安排发布并被数据源收录后，会自动获取。

联网失败时继续使用已有数据，稍后自动重试。没有正式公告的年份不猜测调休。新数据写入后，日历运行约一分钟内读取；关闭日历时 Windows 可能暂停它。

暂停、查看状态、卸载

在开始菜单打开“中国节假日日历”，可以启用、暂停本次会话、立即检查数据、查看更新状态或卸载。关闭管理窗口不会关闭日历标记。

暂停后，下次登录仍会自动启用。完全移除请在 Windows“设置 → 应用 → 已安装的应用”中卸载“中国节假日日历（预览版）”；卸载会移除自动任务并恢复原日历外观。

适用范围

本预览版仅允许安装在 Windows 11 23H2（22631）x64。日期标记的遮挡、翻月、深浅主题及不同缩放的效果仍需在目标设备验收。不能和另一套 Windhawk 同时运行。

程序只标注数据源收录的安排，不替代公司排班；不会自动把所有普通周末标成法定节假日。

数据依据国务院办公厅公告，机器可读数据来自 holiday-cn。项目基于 Windhawk 与 Notification Center Styler，源码和许可证随安装包保存在安装目录的 Source、licenses 中。预览版本 0.5.3。
